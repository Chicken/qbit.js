# qBit.js

A qBittorrent library made with TypeScript.  
Targets qBittorrent 5.2.0 / WebAPI 2.15.1.  
Currently just an API wrapper, planning to be a proper client.  
Only supports ESM, go away with your CJS.  
Proper documentation is on the todo.

Authentication uses the qBittorrent WebUI API key. Generate one from the qBittorrent UI under Options -> Web UI.
